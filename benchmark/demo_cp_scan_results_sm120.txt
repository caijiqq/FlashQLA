General multi-rank AutoCP communication prototype (2026-10-31):
- Replaces the abandoned two-rank, one-sequence send/recv experiment.
- File: blackwell_sm120/cp_comm.py. Forward all-gathers (h, M), then copies
  the rank interval needed by backward into a per-forward CPCache.remote_m.
  The packed h receive buffer is not retained. Backward all-gathers only dh.
- Intervening ranks contain only the spanning sequence, so first/last M agree.
  At the end rank, start from its dh directly (fallback[-1] = False), because
  the received last-sequence M may belong to another sequence. Clone the mask
  to leave the original context's cached mask unchanged.
- Cache includes unused endpoint M slots to retain existing scan indexing.
  With no following rank, cache is an empty tensor (not None); all ranks must
  still execute the same dh-only collective. No world-size-specific branch.
- Shared preprocess.py adds one default-off cache_remote_m argument and one
  cache field. Backward selects the matching protocol from that per-forward
  cache. SM90/SM100 files and default dispatch are unchanged.
- demo_dual_cp.py retains baseline / aggregate / comm / both modes. comm enables
  remote-M reuse; aggregate enables the existing BF16 KxV WS reverse kernel.
  The default library entry point still uses the original protocol.
- Uses build_cp_context(enable_inter=True, enable_intra=True, is_train=True),
  with the real AutoCP decision and no forced partitions. Supports arbitrary
  valid WORLD_SIZE from torchrun and packed global --seq-lengths.
