Run from repository root:
.venv/bin/python -m benchmark.demo_cp_scan --heads H --segments S --seed SEED

Validation:
- Each configuration tests packed sequence lengths 1, 2, 5, 17, 65.
- Near-identity and dense nonsymmetric transition matrices.
- Zero and nonzero initial gradients.
- All/none/alternating/random fallback masks.
- 16 combinations x 20 repeats per configuration, 1920 repeats over six runs.
- Each repeat agrees bit-for-bit with its first output and passes the independent
  PyTorch recurrence with explicit BF16 operand rounding.
- Maximum observed relative-max error in the six stress runs: 8.175e-03.
  Metric: max(abs(actual-reference)) / max(max(abs(reference)), 1e-6).
  Acceptance threshold: 2e-02.
- Final four configurations also assert exact dh copying when all history resets.
- Benchmark workload outputs checked before timing and after CUDA Graph replay.

Timing:

- Five warmup graph replays per candidate.
- 100 kernel calls per graph, nine interleaved measurement rounds.
- Candidate order rotates and reverses; table reports median microseconds.
- Timed workload retains all history (all fallback).
- Ratios below use medians; small differences are sensitive to laptop GPU clocks.

Limits:
- Compute Sanitizer remains unvalidated: a previous attempt on this WSL/WDDM
  setup failed to initialize the debugger interface. It was not rerun in this batch.
  Repeated numerical checks do not prove absence of races.
- Synthetic inputs and one laptop GPU; no multi-GPU or end-to-end claim.
- VxK layout and other dtypes are outside this prototype.
- A prior forward-aggregation baseline numerical failure is unresolved and is
  outside this reverse-aggregation validation.
- No SM90/SM100 code, communication, correction kernel, or production dispatch
  was modified by this validation.
